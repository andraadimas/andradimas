## 🚀 Cara Deploy ke Vercel

Folder ini sudah dilengkapi berkas `vercel.json` dan telah disesuaikan agar dapat langsung diunggah:

### Metode 1: Drag-and-Drop (Tanpa Koding / Paling Cepat)
1. Buka peramban dan kunjungi [vercel.com](https://vercel.com). Masuk atau buat akun gratis.
2. Masuk ke halaman **Dashboard** ➔ klik tombol **Add New...** ➔ pilih **Project** (atau langsung buka [vercel.com/new](https://vercel.com/new)).
3. Seret (*drag & drop*) seluruh folder `andra-dimas-portfolio` ke area upload yang disediakan Vercel.
4. Berikan nama proyek (misal: `andra-dimas`), lalu klik tombol **Deploy**.
5. Dalam beberapa detik, website Anda akan langsung aktif dengan tautan publik gratis (contoh: `https://andra-dimas.vercel.app`) lengkap dengan SSL gratis!

### Metode 2: Import dari GitHub
1. Buat repository baru di akun GitHub Anda (misal: `andra-dimas-portfolio`).
2. Unggah berkas proyek ini ke repository tersebut.
3. Di Vercel, pilih **Import Git Repository**, pilih repositori yang baru Anda buat, lalu klik **Deploy**.
4. Setiap kali Anda memperbarui kode di GitHub, Vercel akan otomatis melakukan build dan deploy terbaru secara otomatis.

### Metode 3: Melalui Vercel CLI
Buka terminal / PowerShell di dalam folder ini:
```bash
npm i -g vercel
vercel
```
Ikuti instruksi singkat di terminal untuk menghubungkan akun Vercel Anda.
